# GW Photography V2

Premium editorial redesign for Grace Westray Photography.

## Local run
```powershell
npm install
npm run dev
```
Then open http://localhost:3000

## Notes
- Original photography retained under `public/images`.
- `.env.local`, `.git`, `.next` and `node_modules` are intentionally excluded.
- The galleries use a responsive editorial masonry layout rather than square crops.
- Replace the enquiry email in `app/contact/page.tsx` when Grace confirms the preferred address.
